## ✨ About

**Plantory**는 반려 식물을 키우는 사람들을 위한 스마트 관리 앱입니다.

- 🪴 **식물 등록** — 내 식물을 등록하고 관리
- 💧 **물주기 알림** — 식물별 맞춤 물주기 리마인더
- 📊 **성장 기록** — 식물의 성장 과정을 사진으로 기록
- 🌤️ **환경 정보** — 날씨에 따른 관리 팁 제공
